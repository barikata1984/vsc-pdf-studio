# 手動確認の一覧

change `improve-render-performance` の各手順の前後で、表示側の機能が壊れていないことを人の操作で確かめる。
拡張機能開発用のウィンドウで測定用の文書を開き、上から順に実行して結果を書き込む。
結果は 良 (期待どおり)、否 (期待と違う。内容を欄に書く)、未 (未実施) のいずれかで書く。
段階の列は、変更前と、tasks.md の手順 2 から 5 の各完了時点を指す。

操作の名前は、道具の並びのボタンに付いた説明文 (Select、Highlight、Annotate、Erase、Add comment など) に合わせている。
選択して出る小さな道具の並びは、文字を選ぶと選択箇所の近くに現れるもの (Copy、Highlight、Comment、Underline、Strike Out、Bookmark) を指す。

| 項目 | 操作 | 期待する結果 | 変更前 | 手順 2 後 | 手順 3 後 | 手順 4 後 | 手順 5 後 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 文書の表示 | PDF を VS Code で開く | 全ページが縦に並んで表示され、総ページ数の表示が実際のページ数と一致する |  |  |  |  |  |

| 蛍光ペン | 文字を選び、小さな道具の並びの Highlight を押す (または Highlight の状態で文字をなぞる) | 選んだ範囲が現在の色で塗られる |  |  |  |  |  |
